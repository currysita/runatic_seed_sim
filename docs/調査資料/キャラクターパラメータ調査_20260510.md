## 調査対象

### 1. ルナティックドーン3（参考資料）

**資料：** `参考資料/他ゲームの資料/lunatic_dawn_3_design.md.pdf`

#### ゲームの思想

- コアコンセプト：「シナリオに束縛されずに思うがままに生き、世界を動かす」
- 主人公は世界の傍観者ではなく、世界の住人のひとり
- 「物語を追う」のではなく「物語を自分で紡ぐ」体験

#### キャラクターパラメータ

| パラメータ | 内容 |
|---|---|
| 体力 / 魔力 | 戦闘能力の基礎値 |
| 名声 | 依頼の受注・結婚・称号に影響 |
| 善悪値 | 行動の積み重ねで変動。仲間・依頼の種類に影響 |
| 秩序混沌値 | 所属勢力・依頼の傾向に影響 |
| 年齢 | 老化・引退・世代交代のトリガー |
| 資産 | 家・装備・結婚に必要 |

#### 戦闘パラメータ

| パラメータ | 内容 |
|---|---|
| 攻撃力 | 武器・筋力で決定 |
| 防御力 | 防具・体力で決定 |
| 命中率 | 技量・武器種で決定 |
| 回避率 | 敏捷性・防具で決定 |
| 魔法力 | 習得呪文・魔力で決定 |

#### NPCシステム

- 世界には最大255名のNPCが自律的に活動
- NPCはプレイヤーと同様に依頼をこなし、成長し、結婚し、死亡する
- NPC同士の関係性（仲間・敵・夫婦・親子）がゲーム内で動的に生成される
- セーブデータにはNPC_ID・年齢・名声・善悪値・秩序混沌値・配偶者ID・子供IDが記録される

#### シード設計（参考）

| 用途 | シードの決め方 |
|---|---|
| 世界の初期勢力配置 | マスターシード |
| NPCの初期生成 | マスターシード + NPC_ID |
| ダンジョン生成 | マスターシード + クエストID |
| 依頼内容の生成 | マスターシード + 日付 + 依頼カウンター |

### 2. Web調査：RPGパラメータ設計

**調査クエリ：**
- 「ブラウザゲーム RPG キャラクターパラメータ 設計 一覧 観察型 自動生成」
- 「RPG character parameters design idle game simulation 2024 2025」

**調査結果の要点：**

- パラメータ設計はコンセプトから出発するのが原則。数値の細部より「何を表現したいか」が重要
- 基本値 × 職業補正 × レアリティ補正 = 実装パラメータ、という計算式アプローチが一般的
- アイドル系RPGでは「数字が常に上がる」「複数の数字が同時に上がる」設計が鍵
- 2024〜2025年のアイドルRPGのセッション数は前年比35%増と市場成長中

## 調査結果：パラメータ案

### カテゴリ1：基本情報

| パラメータ | 説明 | ルナドン3参考 |
|---|---|---|
| id | キャラクター識別子 | ◎ |
| 名前 | 自動生成 | ◎ |
| 性別 | 男・女 | ◎ |
| 年齢 | 経過で加算、引退・死亡のトリガー | ◎ |
| 職業 | 戦士・盗賊・魔術師・商人など | ◎ |

### カテゴリ2：能力値

| パラメータ | 説明 |
|---|---|
| 体力 | HP・戦闘系クエストの成功率に影響 |
| 技量 | 命中・精密作業系クエストに影響 |
| 知力 | 魔法・交渉・謎解き系クエストに影響 |
| 敏捷 | 回避・逃走・運搬系クエストに影響 |
| 魅力 | 護衛・外交・結婚に影響 |

### カテゴリ3：社会的パラメータ

| パラメータ | 説明 | ルナドン3参考 |
|---|---|---|
| 名声 | クエスト受注の幅・称号・結婚に影響 | ◎ |
| 善悪値 | -100〜100。受けられるクエストの傾向が変わる | ◎ |
| 秩序混沌値 | -100〜100。所属しやすい勢力が変わる | ◎ |
| 資産 | 所持金。装備・訓練・結婚に必要 | ◎ |

### カテゴリ4：ひらめき関連（このゲーム固有）

| パラメータ | 説明 |
|---|---|
| ひらめき感受性 | ひらめきをどれだけ強く受け取るか。高いと小さなひらめきでも大きく行動が変わる |
| 根気強さ | 受け取ったひらめきをどれだけ長く保てるか。低いとすぐ元の行動パターンに戻る |
| 現在の指針 | 直近のひらめきから設定された短期的な行動方針 |
| 価値観 | 「名声重視」「安定重視」など長期的な判断基準 |

**感受性と根気強さの組み合わせによるキャラクター像：**

| 感受性 | 根気強さ | キャラクター像 |
|---|---|---|
| 高 | 高 | 一度感化されると人生を変えてしまう熱狂型 |
| 高 | 低 | 次々と新しいことに飛びつくが続かない気分屋 |
| 低 | 高 | 動かすのは難しいが、一度動いたら頑固に続ける職人気質 |
| 低 | 低 | 何にも影響されず、淡々と自分のペースで生きる安定型 |

### カテゴリ5：状態・ライフイベント

| パラメータ | 説明 | ルナドン3参考 |
|---|---|---|
| 現在の状態 | クエスト中・休息中・引退・死亡 | ◎ |
| 配偶者ID | 結婚相手のID | ◎ |
| 子供ID一覧 | 子供のID配列 | ◎ |
| 称号 | 名声・善悪値から自動付与 | ◎ |

## Sprint 1-1 での採用優先度

| 優先度 | パラメータ | 理由 |
|---|---|---|
| 必須 | id・名前・性別・年齢・職業 | キャラクターの最小単位 |
| 必須 | 体力・技量・知力・敏捷・魅力 | クエスト成否の計算に必要 |
| 必須 | 名声・善悪値・資産・現在の状態 | ゲームループの根幹 |
| 後回し | ひらめき関連 | Sprint 4-2 で追加 |
| 後回し | 配偶者・子供 | 世代交代実装時に追加 |
| 後回し | 称号 | Sprint 4以降 |

## 所感・気づき

- ルナドン3のパラメータ設計は「人生のシミュレーション」を意識しており、年齢・善悪値・秩序混沌値の3軸が社会的な立ち位置を決める構造になっている
- このゲーム固有の「ひらめき感受性」は、同じひらめきでもキャラクターの個性によって反応が異なることを表現するために必要
- 能力値5種（体力・技量・知力・敏捷・魅力）はクエストのカテゴリと1対1で対応させると設計がシンプルになる
- 「ひらめき感受性」と「根気強さ」は別パラメータとして分離した。感受性は「どれだけ強く受け取るか」、根気強さは「どれだけ長く維持できるか」という異なる軸であり、組み合わせによってキャラクターの個性が自然に生まれる
