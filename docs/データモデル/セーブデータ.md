# セーブデータモデル

- version: 0.1
- 作成日: 2026-05-10
- 参照資料: `docs/概念設計/シード設計.md`

---

## 設計思想

**「シードで生成できるものは保存しない。変化分だけを保存する。」**

マスターシードがあれば世界の初期状態は常に再現できる。
セーブデータにはシードで再現できない「プレイの積み重ね」だけを持つ。
これによりセーブデータを最小限に保てる。

---

## 世界線セーブデータ

世界全体の状態を保存する。マスターシードと、シードでは再現できない変化分を持つ。

### パラメータ

| パラメータ名 | 型 | 説明 |
|---|---|---|
| マスターシード | integer | 世界全体の再現に使うシード値 |
| ゲーム内日付 | object | 現在の年・月・日 |
| 勢力バランス | object | 秩序・混沌・善・悪の現在の勢力値（初期値からの変化分） |

### JSONサンプル

```json
{
  "マスターシード": 583920,
  "ゲーム内日付": { "年": 12, "月": 3, "日": 8 },
  "勢力バランス": { "秩序": 45, "混沌": 30, "善": 60, "悪": 40 }
}
```

## キャラクターセーブデータ

キャラクター1人分の変化した状態を保存する。
初期パラメータはシードから生成できるため保存しない。
保存するのは「プレイヤーの割り振り」と「プレイ中の変化分」のみ。

### パラメータ

| パラメータ名 | 型 | 説明 |
|---|---|---|
| id | string | キャラクター識別子 |
| 初期割り振り | object | プレイヤーがボーナスポイントを割り振った配分 |
| 名声 | integer | 現在の名声値 |
| 善悪値 | integer | 現在の善悪値 |
| 秩序混沌値 | integer | 現在の秩序混沌値 |
| 資産 | integer | 現在の所持金 |
| 現在の状態 | string | クエスト中 / 休息中 / 引退 / 死亡 |
| クエスト履歴 | string[] | 完了したクエストIDの一覧 |
| 配偶者ID | string / null | 結婚相手のキャラクターID |
| 子供ID一覧 | string[] | 子供のキャラクターID配列 |
| 称号 | string / null | 現在の称号 |

### JSONサンプル

```json
{
  "id": "chara_001",
  "初期割り振り": { "体力": 5, "技量": 0, "知力": 0, "敏捷": 3, "魅力": 2 },
  "名声": 120,
  "善悪値": 70,
  "秩序混沌値": 20,
  "資産": 340,
  "現在の状態": "クエスト中",
  "クエスト履歴": ["quest_042", "quest_107"],
  "配偶者ID": "chara_023",
  "子供ID一覧": ["chara_088"],
  "称号": "大陸の英雄"
}
```

## シードで生成できるもの・セーブデータに保存するものの境界線

| データ | シードで生成 | セーブデータに保存 |
|---|---|---|
| キャラクターの素質（能力値ベース） | ◎ | — |
| ボーナスポイントの総量 | ◎ | — |
| ボーナスポイントの割り振り配分 | — | ◎（初期割り振り） |
| 名声・善悪値・資産などの変化 | — | ◎ |
| クエストの内容 | ◎ | — |
| クエストの結果・履歴 | — | ◎ |
| 結婚・子供などのライフイベント | — | ◎ |
