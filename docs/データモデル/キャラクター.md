## パラメータ一覧

### カテゴリ1：基本情報

| パラメータ名 | 型 | 範囲 | 説明 |
|---|---|---|---|
| id | string | - | キャラクター識別子 |
| 名前 | string | - | 自動生成 |
| 性別 | string | 男 / 女 | - |
| 年齢 | integer | 15〜 | 経過で加算。引退・死亡のトリガー |
| 職業 | string | 戦士 / 盗賊 / 魔術師 / 商人 | - |

### カテゴリ2：能力値

シードからキャラクターの「素質」（ベース値）を生成し、プレイヤーがボーナスポイントを上乗せして初期値を確定する（ウィザードリィ方式）。

| パラメータ名 | 型 | 範囲 | 説明 |
|---|---|---|---|
| 体力 | integer | 1〜100 | 戦闘系クエストの成功率に影響 |
| 技量 | integer | 1〜100 | 精密作業・命中系クエストに影響 |
| 知力 | integer | 1〜100 | 魔法・交渉・謎解き系クエストに影響 |
| 敏捷 | integer | 1〜100 | 回避・逃走・運搬系クエストに影響 |
| 魅力 | integer | 1〜100 | 護衛・外交・結婚に影響 |

**生成フロー：**
```
シード → 素質（ベース値・ボーナスポイント総量）
              ↓
         プレイヤーがボーナスポイントを割り振り
              ↓
         初期パラメータ確定
```

| 項目 | シードで生成 | セーブデータに保存 |
|---|---|---|
| 能力値のベース値 | ◎ | — |
| ボーナスポイントの総量 | ◎ | — |
| ボーナスポイントの割り振り配分 | — | ◎ |

### カテゴリ3：社会的パラメータ

| パラメータ名 | 型 | 範囲 | 説明 |
|---|---|---|---|
| 名声 | integer | 0〜 | クエスト受注の幅・称号・結婚に影響 |
| 善悪値 | integer | -100〜100 | 受けられるクエストの傾向が変わる |
| 秩序混沌値 | integer | -100〜100 | 所属しやすい勢力が変わる |
| 資産 | integer | 0〜 | 装備・訓練・結婚に必要 |

### カテゴリ4：ひらめき関連

| パラメータ名 | 型 | 範囲 | 説明 |
|---|---|---|---|
| ひらめき感受性 | integer | 1〜100 | ひらめきをどれだけ強く受け取るか。高いと小さなひらめきでも行動が大きく変わる |
| 根気強さ | integer | 1〜100 | 受け取ったひらめきをどれだけ長く保てるか。低いとすぐ元の行動パターンに戻る |
| 現在の指針 | string | - | 直近のひらめきから設定された短期的な行動方針 |
| 価値観 | string | 名声重視 / 安定重視 / 自由重視 / 富重視 | 長期的な判断基準 |

### カテゴリ5：状態・ライフイベント

| パラメータ名 | 型 | 範囲 | 説明 |
|---|---|---|---|
| 現在の状態 | string | クエスト中 / 休息中 / 引退 / 死亡 | - |
| 配偶者ID | string / null | - | 結婚相手のキャラクターID |
| 子供ID一覧 | string[] | - | 子供のキャラクターID配列 |
| 称号 | string / null | - | 名声・善悪値から自動付与 |

## 感受性と根気強さの組み合わせ

| 感受性 | 根気強さ | キャラクター像 |
|---|---|---|
| 高 | 高 | 一度感化されると人生を変えてしまう熱狂型 |
| 高 | 低 | 次々と新しいことに飛びつくが続かない気分屋 |
| 低 | 高 | 動かすのは難しいが、一度動いたら頑固に続ける職人気質 |
| 低 | 低 | 何にも影響されず、淡々と自分のペースで生きる安定型 |
